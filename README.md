# アイアンウォーカー（walkgame）

スマホのブラウザで遊べる、ロボットが主役の近未来 **位置情報RPG** です。
人型ロボット「ウォーカー」のパイロットとして実際に街を歩き、近づいた敵マシンをターン制バトルで撃破してレベルを上げます。

**▶ あそぶ： https://novosevenad-afk.github.io/walkgame/**

インストール不要・ビルド不要の静的サイト（HTML / CSS / JavaScript）で、PWA としてホーム画面にも追加できます。

## あそびかた

1. タイトルでパイロット名を入力して「出撃する」（位置情報の許可が必要）
2. 地図上の敵マシンに近づく（黄色い点線の円＝約60m以内）
3. 敵をタップするとバトル開始
   - **攻撃**（ヒートブレードで斬る）/ **スキル**（ENを使う）/ **アイテム** / **防御**（受けるダメージ半分）/ **撤退**
   - **オートバトル**：HPが減ったら回復、それ以外は攻撃を自動でくり返す
4. 経験値でレベルアップ、クレジットでパーツを買って強くなる

### 画面下のメニュー

| ボタン | 内容 |
| --- | --- |
| 機体 | ステータスと装備。買った武器・装甲はなくならず、いつでも付け替えられる |
| アイテム | アイテムを使う |
| メニュー | エネミー図鑑・設定 |
| ウォークモード | ON / OFF の切り替え |

### ウォークモード

画面下の「ウォークモード」を ON にすると、歩いていて約60m以内に敵が入ったときに自動でバトルが始まります（オートバトルで戦います）。

- 📦 補給コンテナも自動で開けます
- 🔋 充電ステーション・📡 司令部では、HPかENが減っていれば自動で回復します（回復はバトルより先に行います）
- HPが3割以下のとき、暴走AI オメガ、撤退した直後の敵とは自動では戦いません
- バトルのあとは4秒あけてから次の敵を探します

GPS が使えない場所や PC では **デモモード**（地図タップ・十字キーで移動）で遊べます。

### 地図上のもの

| アイコン | 内容 |
| --- | --- |
| 🪲🛸🛰️🐍🤖… | 敵マシン。10分ごとに入れかわる。レベルが上がると強い敵が出現 |
| 👁️ | まれに出現する強敵「暴走AI オメガ」。必ずレアチップを落とす |
| 🔋 | 充電ステーション：HP・EN全回復（3分で再使用可） |
| 📦 | 補給コンテナ：クレジットやアイテム（30分で補充） |
| 🔧 | パーツショップ：アイテム・武器・装甲を買える |
| 📡 | 司令部：次のレベルまでの経験値を教えてくれる＋全回復 |

敵とスポットの配置は「場所＋時間帯」から決まるため、同じ場所・同じ時間なら誰が見ても同じ配置になります。
敵はなるべく道路の上に出ます（OpenStreetMap の道路データを [Overpass API](https://overpass-api.de/) から取得し、端末に保存して使い回します。取得できないときや近くに道路がないときは元の位置に出ます）。

### その他の要素

- スキル：リペア / ミサイル / EMPショック / フルリペア / 軌道爆撃（レベルで習得）
- 装備：ブレード・装甲 各6段階
- パワーチップ・アーマーチップ・コアチップ（永久ステータスアップ）
- BGM：フィールドと戦闘で別のオリジナル曲（設定で ON/OFF）
- エネミー図鑑、移動距離の記録
- セーブは端末内（localStorage）に自動保存

## スマホで遊ぶには（公開方法）

位置情報 API は **HTTPS** でしか動かないため、HTTPS で配信する必要があります。

### GitHub Pages（おすすめ）

1. このブランチを `main` にマージ
2. GitHub のリポジトリ設定 → **Pages** → Source を **GitHub Actions** に変更
3. `.github/workflows/pages.yml` が自動でデプロイします
4. `https://novosevenad-afk.github.io/walkgame/` をスマホで開く
5. ブラウザのメニューから「ホーム画面に追加」するとアプリのように使えます

### ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く（localhost は HTTPS なしでも位置情報OK）
```

## ファイル構成

```
index.html            画面レイアウト
css/style.css         ドラクエ風ウィンドウなどのスタイル
js/main.js            地図・GPS・メニュー・スポット・デモモード
js/battle.js          ターン制バトル
js/world.js           位置ベースのモンスター/スポット生成
js/player.js          プレイヤー状態・セーブ
js/data.js            モンスター・じゅもん・アイテム・装備データ
js/sound.js           WebAudio の効果音
js/util.js            乱数・距離計算など
sw.js                 オフライン用 Service Worker
lib/leaflet/          地図ライブラリ Leaflet 1.9.4（BSD-2-Clause）
```
