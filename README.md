# ウォーククエスト（walkgame）

スマホのブラウザで遊べる、ドラクエウォーク風の **位置情報RPG** です。
実際に歩いてモンスターに近づき、ターン制バトルで倒してレベルを上げます。

**▶ あそぶ： https://novosevenad-afk.github.io/walkgame/**

インストール不要・ビルド不要の静的サイト（HTML / CSS / JavaScript）で、PWA としてホーム画面にも追加できます。

## あそびかた

1. タイトルで名前を決めて「ぼうけんに でる」（位置情報の許可が必要）
2. 地図上のモンスターに近づく（黄色い点線の円＝約60m以内）
3. モンスターをタップするとバトル開始
   - **こうげき** / **じゅもん** / **どうぐ** / **ぼうぎょ**（受けるダメージ半分）/ **にげる**
   - **オートバトル**：HPが減ったら回復、それ以外はこうげきを自動でくり返す
4. 経験値でレベルアップ、ゴールドで装備を買って強くなる

GPS が使えない場所や PC では **デモモード**（地図タップ・十字キーで移動）で遊べます。

### 地図上のもの

| アイコン | 内容 |
| --- | --- |
| 🟢🍄🦇🐍👺… | モンスター。10分ごとに入れかわる。レベルが上がると強いモンスターが出現 |
| 😈 | まれに出現する強敵「まおうのかげ」。必ずレアアイテムを落とす |
| ⛲ | かいふくのいずみ：HP・MP全回復（3分で復活） |
| 🎁 | たからばこ：ゴールドやアイテム（30分で復活） |
| 🏠 | どうぐや：アイテム・武器・防具を買える |
| ⛪ | きょうかい：次のレベルまでの経験値を教えてくれる＋全回復 |

モンスターとスポットの配置は「場所＋時間帯」から決まるため、同じ場所・同じ時間なら誰が見ても同じ配置になります。

### その他の要素

- じゅもん：ヒール / ファイア / サンダー / ハイヒール / メテオ（レベルで習得）
- 装備：武器・防具 各6段階
- ちからのたね・まもりのたね・いのちのきのみ（永久ステータスアップ）
- BGM：フィールドと せんとうで別のオリジナル曲（せっていで ON/OFF）
- モンスターずかん、歩いた距離の記録
- セーブは端末内（localStorage）に自動保存

## スマホで遊ぶには（公開方法）

位置情報 API は **HTTPS** でしか動かないため、HTTPS で配信する必要があります。

### GitHub Pages（おすすめ）

1. このブランチを `main` にマージ
2. GitHub のリポジトリ設定 → **Pages** → Source を **GitHub Actions** に変更
3. `.github/workflows/pages.yml` が自動でデプロイします
4. `https://novosevenad-afk.github.io/walkgame/` をスマホで開く
5. ブラウザのメニューから「ホーム画面に追加」するとアプリのように使えます

### ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く（localhost は HTTPS なしでも位置情報OK）
```

## ファイル構成

```
index.html            画面レイアウト
css/style.css         ドラクエ風ウィンドウなどのスタイル
js/main.js            地図・GPS・メニュー・スポット・デモモード
js/battle.js          ターン制バトル
js/world.js           位置ベースのモンスター/スポット生成
js/player.js          プレイヤー状態・セーブ
js/data.js            モンスター・じゅもん・アイテム・装備データ
js/sound.js           WebAudio の効果音
js/util.js            乱数・距離計算など
sw.js                 オフライン用 Service Worker
lib/leaflet/          地図ライブラリ Leaflet 1.9.4（BSD-2-Clause）
```
